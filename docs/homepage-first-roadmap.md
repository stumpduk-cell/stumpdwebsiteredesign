# Stump’d redesign — homepage-first roadmap

## Decision

Begin the visual redesign with the homepage rather than treating the Schools page as the visual origin of the site.

The Schools work remains valuable: its approved content structure, Spark facts and `Spark → Foundation → Core` pathway become requirements for the later Schools page. The static Schools prototype is a content-flow wireframe only. It does not define the new site-wide art direction.

## Why homepage first

The homepage must establish the decisions every audience page inherits:

- what Stump’d is within the first screen;
- how mental strength, cricket and wider life connect;
- the site-wide visual system around the locked logo and colours;
- navigation by audience and/or offer;
- typography, spacing, photography and interaction rules;
- the priority journeys for schools, clubs, parents/players and partners; and
- the balance between brand storytelling and purposeful calls to action.

Starting there avoids designing Schools in isolation and then forcing the rest of the website to imitate it. It also provides a better place to decide which current visual ideas deserve to survive the brand-led reset.

## Recommended sequence

1. Audit the current homepage and global header/footer on desktop and mobile.
2. Confirm the new information architecture and primary audience routes.
3. Produce a homepage content outline before visual styling.
4. Explore a fresh desktop and mobile visual direction using the locked brand assets.
5. Approve the global system: navigation, type, colours, image treatment, spacing and CTA rules.
6. Build the homepage direction in an unpublished Wix copy or review prototype.
7. Apply the approved system to Schools, carrying forward the completed Spark/pathway work.
8. Review remaining pages against the same system and remove redundant/outdated routes.
