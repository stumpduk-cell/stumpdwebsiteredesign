# Schools page direction prototype

`index.html` is the homepage-first visual concept. `schools.html` preserves the earlier approved Schools content-flow wireframe so its Spark/pathway work is not lost.

Open `index.html` in a browser. The logo and photography are deliberately represented by labelled placeholders because the exact supplied PNG and original delivery photographs are not present as repository files. Replace those placeholders only with owner-supplied assets; do not recreate or generate them.

The homepage prototype gives schools, clubs, players and parents equal route prominence, keeps Captain’s Compass quiet during beta, uses the exact approved Wix theme colours and treats Instagram as a restrained current-activity module rather than the final action.

The prototypes demonstrate content order, hierarchy, pathway behaviour, colour roles and mobile stacking. They are not intended to replace Wix or be deployed as the production website.

Do not paste these files into a Wix HTML embed. Rebuild an approved direction with native Wix sections, containers, text, images and links so Wix remains editable and its SEO, Bookings, navigation and responsive behaviour remain intact. See `docs/owner-next-steps.md` for the handoff sequence.

The Codex green Diff panel displays this file’s source rather than rendering it. Do not request visual approval from that view; supply rendered desktop and mobile screenshots or a browser-accessible preview first.

Open `PREVIEW.md` and use its Desktop and Mobile image links to review the rendered design boards. The SVGs can also be opened directly from `prototype/previews/`.
